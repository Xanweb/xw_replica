# Replica

Replica is a free [ConcreteCMS](https://www.concretecms.org/) theme by [Xanweb](https://www.xanweb.com/). Its design is based on the Elemental theme that ships with ConcreteCMS.

![Replica theme screenshot](themes/xw_replica/thumbnail.png)

## Requirements

- ConcreteCMS 9.3 or later
- PHP 7.4 to 8.4

## Install

From the ConcreteCMS marketplace, or from this repository:

1. Clone it into your site's `packages` folder:

   ```
   git clone https://github.com/Xanweb/xw_replica.git packages/xw_replica
   ```

2. Log in to your site as an administrator.
3. Go to Dashboard, Extend ConcreteCMS, and find Replica in the list of packages awaiting installation.
4. Click Install.
