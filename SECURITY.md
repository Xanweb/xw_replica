# Security policy

## Supported versions

Only the latest 2.x release of Replica receives security fixes.

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through GitHub:
https://github.com/Xanweb/xw_replica/security/advisories/new

Please include:

- the Replica version, ConcreteCMS version and PHP version
- a description of the problem and its impact
- steps to reproduce, or a proof of concept
- any suggested fix

We will acknowledge your report and keep you informed while we work on a fix.
